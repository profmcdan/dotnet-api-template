Index for `docs/`. The project overview and quick start live in the

|===

  template.

| link:install.adoc[install.adoc]

| link:template-usage.adoc[template-usage.adoc]

== Reading order

New to the project::
link:install.adoc[install.adoc] to install the CLI and scaffold something, then
link:architecture.adoc[architecture.adoc] to understand what you just started.

About to write a feature::
link:design.adoc#_recipes[design.adoc → Recipes].

Starting a new service from this::
link:install.adoc#_install_the_cli[install.adoc → Install the CLI], then
link:template-usage.adoc[template-usage.adoc] for the full option reference.

On call::
link:architecture.adoc#_failure_modes[architecture.adoc → Failure modes] and
link:install.adoc#_troubleshooting[install.adoc → Troubleshooting].
