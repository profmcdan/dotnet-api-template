Index for `docs/`. The project overview and quick start live in the

| Work inside the code: the domain model and its invariants, the `Result` and error model, the

  template.

| link:install.adoc[install.adoc]

| link:template-usage.adoc[template-usage.adoc]
| Reuse it: install the `dotnet new` template on macOS or Windows, generate a project, what each
  parameter changes, editing the template itself, and packaging it for a team.

| PlantUML sources for the diagrams that appear as ASCII art in the documents above, and how to
  render them.
